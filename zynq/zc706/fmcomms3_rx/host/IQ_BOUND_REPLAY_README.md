重启接收 GUI，在 IQ 分析窗口的“QAM 补偿（64 / 256）”页点击“载入参数 / 冻结方案 JSON…”，选择它。程序自动选择绑定的 IQ、还原参数、校验整个文件的 SHA-256、复算并打开诊断。无需再修改参数。文件被移动、缺失、改变或同名采集元数据的采样率不一致时会停止，而不是使用别的文件。当前保存的是绝对路径；移动文件后需重新生成方案。

每份新数据：先按该数据的实际情况完成一次成功的有 PWM 前导、TDCM 补偿分析，再点击同一页的“保存本次IQ绑定复算JSON…”。它保存的是刚才成功分析时的参数，不是此后可能改动的控件值。下次载入新 JSON 自动复算；每个数据各存一个 JSON。若 IQ 在分析期间或成功后发生改变，先重新分析。当前保存入口适用于有 PWM 前导且启用补偿的 TDCM 参数，不是所有旧模式的通用导出；既有其他方案入口不变。自动搜索或无前导方案请继续使用其现有导出功能。

命令行也可由现有通用参数生成绑定方案（示例的路径和数值须用对应文件的实际值）：

```sh
/opt/anaconda3/bin/python3 host/rx706_iq_replay.py IQ.bin 参数.json IQ_replay.json --fs 15360000 --channel 1 --first-tuple 0 --duration 1 --carrier 798105
```

`--carrier` 是原载波相对 LO 的有符号基带频率，单位 Hz，不是目标谐波；命令不会覆盖已有输出文件。通用参数文件不会自动绑定 IQ，此命令必须填入该文件真实的采样率、通道、起点、时长和载波；不能把本次值直接套用到新采集。完整生成和重放均为离线处理，不操作硬件。
