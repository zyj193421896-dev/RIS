# PWM 有效片段搜索

接收分析窗口默认恢复时长为1000ms，PWM设置中默认勾选“自动搜索有效PWM片段”。搜索范围为“起始采样点”后的指定时长，最多1秒，且不超过文件末尾。例如1秒文件的前0.5秒只有噪声或固定状态载波时，可从采样点0开始搜索。

搜索以重叠小窗口读取文件，先排除噪声和稳定单音，再检查两态、符号时钟和PWM脉宽。确认连续8个有效符号后回看前一个重叠区，并在检出的符号段前保留2符号余量，重新运行原有PWM解调。首窗已经有有效PWM时保留原始起点。搜索确认窗中的符号不会作为导频丢弃；校准与解调复用同一段采样。

统计页显示搜索范围及实际重新解调的起点。波形、符号表和导出时间均采用原文件坐标；跳过的前导无信号区域不作为逻辑0或信息比特。首尾不完整符号、无效脉宽和空闲的规则保持原样。没有有效片段时报告搜索失败；若首窗能恢复两态但编码不符，仍保留原有诊断。

PWM读取已支持完整1秒，不再受原4194304点上限限制。其他恢复模式保持原读取上限。长片段所需内存和计算时间随采样率及符号数增加；界面表格仍仅显示前2000行，导出包含全部结果。

搜索用于定位第一个有效PWM符号段，不提供发端包头或帧序号。自动A/B映射仍需参考序列确认。若启用已知循环校验，默认前64个符号用于参考对齐，不参与BER统计，但仍在解调表中。

搜索小窗和最终恢复片段分别统计ADC触限。若开头10ms触限超过0.1%，但整段实际恢复片段低于0.1%，不再因搜索小窗而提前退出；小窗触限比例记入诊断。最终恢复片段仍执行原0.1%拦截，其他恢复模式的拦截不变。所有读取始终检查12位数据范围、文件截断和长度变化；不截去峰值、不替换采样、不自动调节硬件增益。通过触限检查并不代表PWM时钟、两态或编码已锁定。

Python接口通过 `recover_pwm(..., duration_s=1., auto_search=True)` 启用搜索；`auto_search=False` 可保留原来的起点解调方式。

验证命令（在tests目录）：
