# PWM 最简帧：离线多用户解码与误码测试

**历史兼容说明**：2026-11-08起，默认规则已改为仅用户身份前导＋净荷，不再使用缓冲和公共训练，支持时延/脉宽联合调制及下降沿固定拖尾。新界面、码表和速率说明见 [PWM_PULSE_README.md](PWM_PULSE_README.md)。以下保留旧API格式说明。

打开 `rx706_gui.py` 的接收分析窗口。默认模式为 **PWM（占空比）**，默认启用最简帧、用户数 **1**。

默认发端格式，所有长度均为完整PWM周期数：

```
启动缓冲32 | 公共训练64 |
U1身份16 | U1净荷1024 |
U2身份16 | U2净荷1024 | … 按启用的用户数循环
```

单用户仅重复 `U1身份 | U1净荷`。公共前缀只在整段连续传输开始时发送一次，不在每块前重复。

## 配置发端与收端

- 默认频率169.971671 kHz；符号0～7对应20%、27%、34%、41%、48%、55%、62%、69%。每个符号从高状态开始，随后低状态至周期结束。
- 缓冲和训练的默认循环都是 `0 7 1 6 2 5 3 4`。按配置长度循环截取：缓冲32为4遍，训练64为8遍。
- 缓冲长度、缓冲码型、训练长度、训练码型均可修改；长度0可关闭相应部分。训练非零时必须覆盖所有档位至少两次；训练最多4096周期。缓冲允许受损，只作排除和位置标记，不参与拟合，也不要求其接收值完全匹配。
- 点击 **用户身份与净荷 / 已知数据…**，逐用户编辑名称、完整身份序列、净荷符号数、已知数据。身份序列的项数即身份长度，支持4～256周期；净荷1～1000000周期。不同用户允许不同身份长度、不同净荷长度。配置用户数支持1～16；只有前N个用户生效。
- 身份码填写的是PWM符号值，不是比特。默认身份码为16周期，使用0/7两档。修改占空比档位数后，请检查身份、缓冲和训练序列是否合法。
- 用户顺序固定为配置顺序，解码首块允许从其中任一用户起始，后续按该顺序轮询。身份码损坏时仍保留该时隙和其净荷位置，不用参考数据重新对齐。
- 保存/载入帧配置可以保留各段码型、长度、用户配置、频率、占空比映射及参考规则。`pwm_frame_single_user.json`、`pwm_frame_three_users.json` 提供可直接载入的默认示例；发端必须发送相同身份码。

默认身份码如下，可修改：

| 用户 | 完整身份符号序列 |
| --- | --- |
| U1 | `0 0 0 7 7 0 7 7 7 7 0 0 0 0 7 7` |
| U2 | `7 7 0 0 0 0 7 7 7 7 0 0 0 7 7 0` |
| U3 | `7 7 7 0 0 7 0 0 7 0 7 0 7 7 0 0` |

高级参数可设置首身份搜索范围（默认4096周期，0为整个恢复范围）、身份容错数（默认1个符号）和训练残差上限。最简帧保留完整恢复起点，不使用旧PWM搜索裁掉前缀；选取的文件片段必须包含公共训练和首个可识别身份码。如果训练位于更晚的位置，增加搜索范围或调整恢复起点。

## 校准与数据输出

通过前面的已知训练和紧邻的首身份联合定位。对每档训练脉宽取中位数，并检查档位顺序、间距、样本数和训练残差，然后建立实测宽度到标称宽度的映射。净荷不参与这次校准。未找到公共训练/首身份时不输出确认净荷。

符号表新增区段、用户、块号、块内净荷位置、身份有效及完整块列。用户筛选同时作用于表格、CSV和比特流；净荷比特流排除缓冲、训练、身份及前置采样。擦除保留为`???`，不移除位置。CSV保留全部诊断行；另可导出整体、逐用户和逐块JSON统计。

## 已知数据、BER和误块率

勾选 **启用已知净荷 BER / 误块率测试**，在用户配置里填入实际已知净荷。空参考表示该用户未测，不能解释为零误码。

- **符号值**：如 `0 1 2 3 4 5 6 7`，按当前符号二进制映射比较。
- **二进制比特**：如 `000 001 010 …`，空白分隔符被忽略，按MSB优先比较。
- 可用 **载入已知数据文件…** 指定UTF-8文本；它保存为`@绝对路径`。参考文件须继续可读。
- **循环重复已知数据**：参考短于净荷时循环使用；关闭后只比较参考完整覆盖的块，未覆盖块单列。
- **每块从参考起点开始**：适合每块重复相同测试数据。关闭后按每个用户独立、连续地消耗参考；坏块也消耗原来的位置，避免错位掩盖错误。

统计仅覆盖已定位范围内的完整块：

```
BER = 错比特数 / 已判决且有参考的比特数
BLER = 失败块数 / 已知参考覆盖的完整块数
失败块 = 任意错比特、任意擦除，或身份码失败
```

擦除位数单列，不放进BER分母；所有擦除块都计入BLER。尾部不完整块单列，不计BER/BLER。未覆盖参考的完整块也单列。没有已判决比特时BER为“未测”，没有可评估完整块时BLER为“未测”。参考从配置位置直接比较，没有独立BER同步窗，不搜索最优循环相位、不纠正接收数据。没有帧序号时，不能凭这份文件统计采集窗口以外或整轮消失的块。

## 兼容旧单用户文件与模式

取消 **启用最简帧**，可继续使用原来的三连前导、固定帧长与已知循环BER；旧快速预设会自动切回旧格式。PWM v1保留。菜单保留原始IQ、PWM v1、PWM（占空比）、TDCM谐波QAM；周期方波恢复、普通QAM、PWM前导+QAM入口已移除。底层离线算法保留供脚本调用。
