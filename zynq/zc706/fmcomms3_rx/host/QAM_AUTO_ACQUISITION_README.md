## 2026-11-10 弱信号相位回退已通过 `_1` / `_2` 真实数据验证

原相位流程成功时继续使用原流程；失败时，自动模式可使用新的已知前导回退：

1. 整段PWM稳定平台联合拟合相位/频偏，不再只相减两个噪声较大的半前导。按PWM符号删除块估计频偏不确定性。
2. 连续前导及局部频偏一致性共同检查周数。缺失任何前导、接近周数边界、显著局部矛盾或不确定性无法排除另一周数时拒绝。跨帧检验同时考虑短时协方差和四前导块均值；这些是模型性保护，不宣称校准的统计置信概率。
3. 保形三次插值采用原0.20rad（11.46°）留一前导P95门限。同时检查全部内点的P95，避免隐藏早段失败。前20个前导作为校准区，另报告后续条件插值留出误差；这不是重新从零捕获载波/周数的独立实验。
4. 仅用明确已知的四个QAM训练符号做另一组观测。固定PWM到QAM相位偏移只用校准区，后段检查仍为0.20rad门限。校准区相位散布也须通过同一门限。校准/后段成功覆盖率均须≥80%，连续未验证帧不得超过2。该相对相位验证不能单独排除恒定整数周数错误，周数检查由PWM局部频偏承担。

## 相位补偿修复更新

此前自动流程只估计固定原载波和相对时钟，没有持续修正帧内相位，因此四角训练能达到约1.31%而净荷星座仍弯曲。1.31%从来不是全部净荷EVM。

现在默认自动模式增加 `pwm_headers`：从每帧已知PWM的两态差估计公共相位，利用短前导局部频偏检查跨帧相位歧义，再做留一前导验证。少于6个可信前导、观测缺口过大、相位矛盾或变化过快时明确拒绝，不用未知净荷拉正星座。手动和历史绑定回放保持原设置。

同一新_1完整2秒，147/147帧、37632净荷候选：净荷最近邻EVM从7.8245%变成5.2638%，四角训练中位1.3130%。仍有噪声/波形模型残差，未知净荷BER未测，不能把训练EVM替代净荷指标。主图现在明确标补偿后净荷，界面分开显示两个EVM；QAM符号表不会切换到PWM模式。

相位诊断记录见 `数据/验收/analysis_qam10_auto_20261110/phase_compensation_report.json`，本次有效参数已更新为包含相位跟踪的 `effective_recovery.json`。重开旧窗口后按原流程加载BIN及原JSON、2000 ms、默认自动搜索，直接运行。

## 自动验收

1. 独立分析当前RX通道原始IQ频谱，枚举强峰、两种频率符号及正负目标谐波偏移，不能把频谱最大峰直接当原载波。
2. 每个候选必须同时通过完整已知PWM前导和已知QAM训练；不同载波均通过时拒绝歧义，不根据未知净荷EVM选载波。
3. 只用最前面的至多20个已知PWM头拟合相对时钟，检查残差与配置的ppm范围。后续帧独立验证。净荷可以每帧变化，不要求整帧重复。
4. 以自动得到的载波、时钟运行原TDCM后端，保留每帧前导/训练检查。失败时不制造星座锁定或BER。
