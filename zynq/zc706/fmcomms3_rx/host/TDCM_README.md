# TDCM 谐波QAM

用于以方波占空比和时移在某阶谐波上合成QAM的发端。选择“星座处理 → TDCM 谐波QAM”。普通“QAM 解调”和“PWM前导 + QAM”保留，用于直接I/Q成形QAM；独立PWM解调未改变。

本实验默认参数：

| 设置 | 默认值 |
|---|---:|
| QAM阶数（沿用QAM设置） | 256 |
| QAM符号率 | 19.53125 kSym/s |
| 谐波基频 | 19.53125 kHz |
| PWM前导频率 | 19.53125 kHz |
| 目标谐波阶数 | +1 |
| 原载波基带位置 | −0.2 MHz |
| PWM前导序列（沿用混合模式） | 0 0 0 |
| version2总片/前高/后低 | 25 / 5 / 8 |
| PWM→QAM间隔 | 0 µs |
| 幅度系数 / 相位修正 | 1 / 0° |
| 提取符号数 | 0（到文件尾） |

原载波位置应填相对接收LO的有符号频率，不能填目标边带的位置。输入−200 kHz、+1阶、19.53125 kHz时，名义目标边带为−180.46875 kHz；PWM拟合出的残余频偏还会加到两个频点上。实际载波改变后需相应修改，默认−0.2 MHz来自当前实验文件，不是自动估计或固定硬件频偏。

三个20% PWM符号各长51.2 µs，完整前导153.6 µs。片数、PWM序列、脉宽偏移、误差容差、搜索时长、切换间隔沿用“混合模式”及version2设置；TDCM的三个频率在本组单独配置，不修改原PWM或常规QAM的100 kHz默认值。仅在PWM之后确实发送了已知QAM训练符号时，才勾选“启用已知前导同步与频偏校正”。

处理步骤：

1. 按原载波频率数字移频，拟合已知PWM前导，得到数据周期边界。
2. 在PWM稳定高/低片段上联合拟合公共固定频偏和两个复数RF状态。既定时刻的两态参考保留实际幅度和相位，不按每个QAM符号强行复位相位。
3. 移除固定频偏。在每个完整51.2 µs窗口内积分所选谐波的复系数。窗口保持786.432等非整数采样点长度；采样单元采用分数边界解析积分，避免把窗口取整为786/787点而引入原载波泄漏和累计滑移。
4. 采用PWM两态参考、盲归一化或实际发送的QAM训练校准，再作方形QAM最近邻判决。RRC/Rectangular匹配设置不用于TDCM路径。

每个QAM符号必须包含整数个调制周期。谐波阶数可选±1～±32，不可为0，目标频带必须在采样范围内。先处理完整窗口，再输出每个窗口中心的原文件时间；不会把PWM前导或切换间隔当作QAM数据。

## 幅相参考约定

对高电平从周期起点延迟τ、占空比d的两态波形，非零m阶系数按以下约定：

`C_m = (Γ1−Γ0) × d × sinc(m d) × exp[−j2πm(τ/T+d/2)]`

“PWM两态参考”用前导拟合的Γ1−Γ0校准复增益。默认还假定发端将方形QAM最远角点映射到该阶谐波的理论最大幅度 `|Γ1−Γ0|/(π|m|)`。默认满幅映射、时移零点、Γ1/Γ0标签必须与发端一致；若发端使用不同的幅度缩放或固定相位约定，应配置幅度系数和相位修正。该模式不会用数据强行拟合成16×16网格。RIS过渡未稳定或占空比相关响应也可能使前导两态参考失配；单一20%前导不能校正所有非线性响应。

“盲归一化”使用提取系数的RMS和静态相位搜索，仍有90°相位歧义，非均匀符号分布还可能造成幅度估计偏差。幅度系数及相位修正也作用于此模式。

若启用已知QAM训练，则在PWM推算的数据起点后按整数个QAM窗口匹配配置序列，估计剩余固定频偏并从原始IQ重新提取，随后估计复增益；排除这些训练窗口后输出数据。此时训练序列定义幅相参考，不叠加手工幅相修正。没有实际QAM训练时不要启用。

物理模型参考：[Independent control of harmonic amplitudes and phases via a time-domain digital coding metasurface](https://www.nature.com/articles/s41377-018-0092-z)。

## 结果及限制

显示目标阶数、谐波基频、校正后的原载波/谐波频点、PWM候选位置、拟合误差、校准方式和候选比特。`coefficients`保留以ADC counts为单位的复系数，`scatter`为校准后的星座；`time_s`为积分窗口中心。输入bin不修改。

该版本估计固定频偏，不持续跟踪载波或符号时钟漂移；只选择一个PWM候选，不自动分割后续重复帧。已知一帧含N个QAM窗口时，可填“提取符号数=N”避免把下一帧前导计入数据（若有QAM训练，该数包含训练窗口）。0表示处理到文件尾。首尾不完整窗口不输出。

已提取谐波不等于256QAM已锁定。判决EVM不能替代已知净荷参考或证明映射正确；不报告BER。幅相校准或帧边界不符时，即使前导被匹配，也可能得到错误候选符号。

在tests目录运行 `python -m unittest test_tdcm test_gui_layout test_qam_pwm test_qam_preamble test_rx706_qam`。合成发端用占空比和时移构造真实两态脉冲，测试正负阶、非整数窗口、强原载波泄漏、公共频偏、PWM校准、可选QAM训练、GUI交付和模式切换。
