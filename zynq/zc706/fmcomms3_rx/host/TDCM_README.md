# TDCM 谐波QAM

用于以方波占空比和时移在某阶谐波上合成QAM的发端。选择“星座处理 → TDCM 谐波QAM”。普通“QAM 解调”和“PWM前导 + QAM”保留，用于直接I/Q成形QAM；独立PWM解调未改变。

本实验默认参数：

| 设置 | 默认值 |
|---|---:|
| QAM阶数（沿用QAM设置） | 256 |
| QAM符号率 | 19.53125 kSym/s |
| 谐波基频 | 19.53125 kHz |
| PWM前导频率 | 19.53125 kHz |
| 目标谐波阶数 | +1 |
| 原载波基带位置 | −0.2 MHz |
| PWM前导序列（沿用混合模式） | 0 0 0 |
| version2总片/前高/后低 | 25 / 5 / 8 |
| PWM→QAM间隔 | 0 µs |
| 幅度系数 / 相位修正 | 1 / 0° |
| 提取符号数 | 0（到文件尾） |

原载波位置应填相对接收LO的有符号频率，不能填目标边带的位置。输入−200 kHz、+1阶、19.53125 kHz时，名义目标边带为−180.46875 kHz；PWM拟合出的残余频偏还会加到两个频点上。实际载波改变后需相应修改，默认−0.2 MHz来自当前实验文件，不是自动估计或固定硬件频偏。

三个20% PWM符号各长51.2 µs，完整前导153.6 µs。片数、PWM序列、脉宽偏移、误差容差、搜索时长、切换间隔沿用“混合模式”及version2设置；TDCM的三个频率在本组单独配置，不修改原PWM或常规QAM的100 kHz默认值。仅在PWM之后确实发送了已知QAM训练符号时，才勾选“启用已知前导同步与频偏校正”。

处理步骤：

1. 按原载波频率数字移频，拟合已知PWM前导，得到数据周期边界。
2. 在PWM稳定高/低片段上联合拟合公共固定频偏和两个复数RF状态。既定时刻的两态参考保留实际幅度和相位，不按每个QAM符号强行复位相位。
3. 移除固定频偏。在每个完整51.2 µs窗口内积分所选谐波的复系数。窗口保持786.432等非整数采样点长度；采样单元采用分数边界解析积分，避免把窗口取整为786/787点而引入原载波泄漏和累计滑移。
4. 采用PWM两态参考、盲归一化或实际发送的QAM训练校准，再作方形QAM最近邻判决。RRC/Rectangular匹配设置不用于TDCM路径。

每个QAM符号必须包含整数个调制周期。谐波阶数可选±1～±32，不可为0，目标频带必须在采样范围内。先处理完整窗口，再输出每个窗口中心的原文件时间；不会把PWM前导或切换间隔当作QAM数据。

## 幅相参考约定

对高电平从周期起点延迟τ、占空比d的两态波形，非零m阶系数按以下约定：

`C_m = (Γ1−Γ0) × d × sinc(m d) × exp[−j2πm(τ/T+d/2)]`

“PWM两态参考”用前导拟合的Γ1−Γ0校准复增益。默认还假定发端将方形QAM最远角点映射到该阶谐波的理论最大幅度 `|Γ1−Γ0|/(π|m|)`。默认满幅映射、时移零点、Γ1/Γ0标签必须与发端一致；若发端使用不同的幅度缩放或固定相位约定，应配置幅度系数和相位修正。该模式不会用数据强行拟合成16×16网格。RIS过渡未稳定或占空比相关响应也可能使前导两态参考失配；单一20%前导不能校正所有非线性响应。

“盲归一化”使用提取系数的RMS和静态相位搜索，仍有90°相位歧义，非均匀符号分布还可能造成幅度估计偏差。幅度系数及相位修正也作用于此模式。

若启用已知QAM训练，则在PWM推算的数据起点后按整数个QAM窗口匹配配置序列，估计剩余固定频偏并从原始IQ重新提取，随后估计复增益；排除这些训练窗口后输出数据。此时训练序列定义幅相参考，不叠加手工幅相修正。没有实际QAM训练时不要启用。

物理模型参考：[Independent control of harmonic amplitudes and phases via a time-domain digital coding metasurface](https://www.nature.com/articles/s41377-018-0092-z)。

## 结果及限制

显示目标阶数、谐波基频、校正后的原载波/谐波频点、PWM候选位置、拟合误差、校准方式和候选比特。`coefficients`保留以ADC counts为单位的复系数，`scatter`为校准后的星座；`time_s`为积分窗口中心。输入bin不修改。

该版本估计固定频偏，不持续跟踪载波或符号时钟漂移；只选择一个PWM候选，不自动分割后续重复帧。已知一帧含N个QAM窗口时，可填“提取符号数=N”避免把下一帧前导计入数据（若有QAM训练，该数包含训练窗口）。0表示处理到文件尾。首尾不完整窗口不输出。

已提取谐波不等于256QAM已锁定。判决EVM不能替代已知净荷参考或证明映射正确；不报告BER。幅相校准或帧边界不符时，即使前导被匹配，也可能得到错误候选符号。

## 自动补偿组合搜索（有限范围，可导出冻结方案）

在“256QAM 补偿”页点击 **启用自动搜索（使用当前先验）**，会切换到TDCM模式并启用自动搜索。先核对输入文件、Fs、QAM阶数、标称符号率/谐波基频/PWM频率、前导序列、片数及切换间隔，再点击“分析信号”。程序按当前文件重新搜索，不套用之前文件的ppm或增益。取消自动搜索后仍可手动调试各补偿项。

自动模式适用于有已知PWM前导的**整帧重复TDCM波形**，不用于任意调制或随机新净荷。它不自动识别真实Fs、QAM阶数、未知前导/编码或未知标称符号率；每符号整数调制周期的比值沿用用户设置。

默认搜索范围和预算：

| 项目 | 默认 / 限制 |
|---|---|
| 载波候选 | 以TDCM原载波设置为中心±500kHz，在Nyquist内裁剪；从原始谱及平方谱提议最多3个有限谱峰，并通过PWM匹配验证。谱对比度不是SNR。 |
| 周期范围 | 预期整帧周期±1000ppm，可调1～5000ppm。错误帧格式可能被解释为钟差，不能只看ppm值。 |
| 每帧QAM窗口候选 | 64、128、256、512；可填写1～6个16～2048的整数，包含实际QAM训练窗口数。前导结构仍由用户提供。 |
| 补偿组合 | 比较时钟关闭/自动周期、公共相位关闭/均值/平方、PWM两态/盲幅相；提供真实QAM训练时使用训练校准。盲定时只在符合重复模型的盲标定候选中启用。 |
| 精评预算 | 最多12个组合、60秒搜索预算；可调最多24个、180秒。范围内未精评的组合会标明预算限制；不保证全局最优。预算不跳过已开始的处理与最终验证。 |
| 接收约束 | 相位更新率、参考带宽、输入点数上限、前导容差等沿用补偿页和原前导设置；实际采用值在结果中列出。 |

程序先用记录前60%提议载波、重复周期和帧候选，在该前段内用一部分帧标定、另一部分帧选择方案；选择后冻结周期、窗口及盲复增益/模板，再用未参与选择的后段验证，并留一个帧间隔。建议提供至少约12帧；标定、选择、最终验证的实际帧号和时间边界会记录在报告。

评价不仅使用最近邻EVM，还检查前导/帧覆盖率、前段平均星座格点结构分数及独立帧对固定重复模板的误差。默认有效帧覆盖率至少80%、格点结构分数至少0.55，并使用补偿页的误差阈值；这些是算法门限，不是误码率或统计置信概率。评分为选择段重复EVM加覆盖率惩罚；分数接近时优先较少补偿的方案。

最终后段不用于反复重选。若它不通过，结果标为“未通过最终验证”；若不同载波/帧模型在选择段表现接近，标为模型歧义。独立RF参考和真实导频仍可用于接收跟踪，但最终QAM数据窗口不参与盲拟合或方案排名。重复但不成QAM格点的图样、随机新净荷、噪声、超范围和数据不足均不能当成成功锁定。帧倍数等结构可能本来不可唯一识别，应提供更明确的发端帧信息。

## 无 PWM 前导的两态 TDCM（新增，默认关闭）

`rx706_tdcm.recover_tdcm()` 支持 `tdcm_options.acquisition_mode`：

- `pwm`：原流程，默认值；继续使用实际发送的 PWM 前导。
- `no_header_repeat`：没有 PWM，也没有已知 QAM 训练，但整个调制图样重复。已知 Fs、标称符号率、谐波基频、阶数和载波范围后，从独立两态 RF 参考跟踪公共相位，从重复波形估计周期，再盲估一个公共定时偏移和复增益。不会逐个符号消去数据相位。
- `no_header_fixed`：允许随机、非重复载荷；需要用户给定真实符号时钟（配置周期或手动 `period_ppm`）。不提供随机载荷的自动钟差估计。该模式中 `clock_mode=repeat` 会被拒绝。

无前导模式必须选择“盲归一化”，关闭“真实 QAM 训练”，并将“提取符号数”设为 0。这里的“每帧 QAM 窗口数”用于划分分析块，不证明实际协议帧边界。至少需要标定块、3 个独立选择块及 3 个最终验证块。首块和末尾不完整窗口会丢弃。

GUI 在“256QAM 补偿”页新增“0 · 前导与数据获取”。选择无前导方式会启用独立补偿及平方载波参考。勾选“自动搜索并验证补偿组合”后，在当前载波中心的有限范围内提出谱峰候选，比较平方/均值公共相位参考，并在重复模式比较重复窗口长度；随机模式始终保留配置时钟。未勾选时使用手动载波中心、公共相位方式及每块窗口数。无前导情况下不会校验或使用 PWM 参数；也不会把未知序列假定为训练。

搜索范围沿用自动补偿设置：载波默认 ±500 kHz、重复周期默认 ±1000 ppm、窗口候选 64/128/256/512、载波候选最多 3、精评预算默认 12 次/60 秒。支持有界参数调整，但不保证全局最优或任意信号适用。时间预算只限制模型搜索，最终原始采样提取/验证另需时间。多个整数倍重复间隔可以同时通过，选择误差相近的最短窗口；这是分析周期，不能识别发端实际帧长。

标定与验证：只在前 60% 数据中估计时钟、拟合定时/增益并选择方案，最后 40% 不参与模型选择。公共相位在全段使用独立 RF 参考持续跟踪，不使用未知 QAM 判决作为相位参考。对选择段和后段均检查冻结复增益下的最近点误差、格点相干度、标签覆盖；重复模式另检查冻结前段模板误差。载波参考还需通过轴向相干度与受噪声/振铃影响的两态残差检查。无信号、噪声、单音、非网格或假重复等情形测试覆盖，但这些判据不是数学上的通用调制识别证明。

报告“无前导方案 / 验证”页列出采用方式、载波、周期 ppm、偏移、谐波、复增益、相位更新率/带宽、搜索范围、候选拒绝原因、两态参考质量及分段指标。最终后段失败时显示 `test_failed`，不使用该后段重新搜索；没有合格候选时显示“未锁定”并保留原始 IQ。`candidate_validated` 仅表示结构验证通过：90° 旋转、整数符号偏移、发端 Gray 映射及协议帧起点仍未验证，真实 BER 始终为未测。

“导出无前导配置 JSON”包含输入片段 SHA256、通道、Fs、可复算参数和已采用数值。载入时先校验同一输入，然后按相同配置重新估计；它不是冻结训练模板，不能用于另一份文件绕过同步。

### rx_qam_2.bin 的复现设置

该文件没有同名采样参数 JSON，以下 Fs 和发端速率是待核对的手动假设：RX1、Fs=15.36 MSPS、256QAM、标称符号率/谐波基频=19.53125 kHz、谐波 +1、原载波中心 +0.8 MHz、处理 1000 ms、盲归一化、幅度 1、相位 0、提取数 0。选择“无前导：重复图样”，关闭已知 QAM 训练，启用自动组合搜索，保留默认窗口候选与范围，再点击分析。

离线只读验收得到约 786.467626 点/符号（相对标称周期 +45.3006 ppm），采用 256 窗口重复块及平方载波参考，后段覆盖 256/256 标签。最近点误差和重复模板误差仅证明可恢复候选结构，不能作为发端参考 EVM 或 BER。以本次报告实际输出为准。

CLI 示例（输出目录必须不存在）：

```sh
/opt/anaconda3/bin/python3 tests/verify_tdcm_headerless_capture.py /path/rx_qam_2.bin --output /tmp/tdcm-no-header-report --sample-rate 15360000 --symbol-rate 19531.25 --carrier-center 800000
```

当前边界：不自动识别原始字节/IQ排布，不估计未知 Fs，不替代普通直接调制 QAM 的匹配滤波器，不支持未知协议/映射的比特验证，不提供随机载荷盲钟差跟踪或一般信道均衡。两态参考太弱、载波超出搜索范围、周期/结构不匹配、符号不足及独立验证失败均应先排查参数/信号模型，不能靠放宽 EVM 门槛宣称锁定。

## 已知 PWM 的候选提取与稀疏载荷诊断

本工程在用户没有特别说明时，256QAM 使用 Fs=15.36 MSPS、每 symbol 51.2 µs（19.53125 kSym/s）；三个20% PWM前导各同长。上述值作为已知先验，不能据此推断未知文件的协议帧长、切换间隔或实际QAM映射。已有配置按用户选择加载，不强制覆盖。

短 PWM 前导的粗定位仍使用已知高低平台。相邻采样相位差受到有色噪声影响、导致频偏候选被原范围拒绝时，现在会在原频偏范围内拟合完整已知 PWM 模型；仍检查完整前导和原有拟合误差门槛，不通过时不会强行生成符号。

“256QAM 补偿”页关闭“自动搜索并验证补偿组合”，选择“有PWM前导（原流程）”，启用独立补偿，可按已知时序提取候选。每帧 QAM 窗口现允许短载荷；单帧不足16个符号也可查看，但明确提示统计不足。前导匹配、候选复系数提取、重复结构验证和比特验证分别报告。稀疏载荷不因缺少128个格点而禁止候选输出，也不会因此宣称完整256QAM映射已经验证。噪声、错误前导和无前导模式仍保留原获取检查。

重复模式中，前段可以冻结公共复增益与重复模板，用后续帧检查重复性。稀疏重复结构通过与“QAM映射/真实比特已确认”是不同结论；没有实际QAM训练、发端映射或比特参考时仍无真实BER。载入配置时会把实际参数同步回可见控件，避免单次复算后再次分析时使用旧控件值；冻结配置仍受同一IQ片段指纹约束。

对 rx_qam_3.bin，用户已确认上述 Fs 和 symbol/PWM 时长。观测到约15个标称周期的重复间隔；“3个PWM + 12个数据窗口、零切换间隔”是从波形推断的分析模型，载荷数量和切换间隔仍需发端核对。可用前段估计约+45ppm后，按每帧12窗口查看候选；关闭盲定时拟合，保留固定的前导后边界。少量重复点不代表发送或正确恢复了整个256点码本。

## 三个 PWM 后的四角训练与 HEX 净荷

每帧支持：3个20% PWM → 4个已知QAM训练 → N个净荷symbol。PWM与QAM每窗51.2µs，Fs=15.36MSPS；默认切换间隔为0，发端有额外间隔时须填写真实值。训练顺序和坐标可配置，并非从净荷判决反推。

本地 ris_codebook_gui.py 与接收端均为高4位I、低4位Q，各轴Gray解码为2*n−15。四个HEX 00、08、88、80分别为(-15,-15)、(-15,+15)、(+15,+15)、(+15,-15)，在I向右、Q向上的图中顺时针排列。FF对应(+5,+5)，88才是右上角。发端生成器使用峰值归一化，接收端使用平均功率归一化，两者相差固定标量，由已知训练的公共复增益吸收；不能把任何256格点编号都当作这套标签。

在“星座处理”选择独立模式“256QAM：3PWM＋四角训练”，或在“256QAM 补偿”页点“3PWM＋四角训练配置（00 08 88 80）”。该配置保留现有净荷数量，将每帧QAM窗口数改为N+4；如净荷12个，填16；如净荷256个，填260。三个PWM不包含在这个窗口数内。再次点击不会重复累加训练长度。“HEX字节（00–FF）”可直接输入00 08 88 80；原十进制模式则须使用0x前缀。也可选择“I/Q电平”输入实际奇数电平。训练必须实际出现在每帧PWM后，不能只在文件开头出现一次。

程序只用已知训练拟合复增益、相位及可选复零点，并在正常/共轭模型间辨识I/Q镜像；参考不能区分模型或拟合不通过时给出失败，不猜映射。最初若干帧用于选定镜像约定，后续帧保持同一约定，并各自利用实际训练更新幅相/零点。坏训练帧单独标记并剔除净荷，不将首帧的短训练频偏噪声外推到整个记录。独立RF公共相位跟踪仍应开启，以处理帧内漂移。

训练从净荷中剔除，在“已知训练 / 映射”页和训练CSV中单独显示期望/观察HEX；净荷表、概览和净荷CSV使用两位大写候选HEX，并保留坐标、比特及距判决边界的信息。距边界提示只是几何量，不是概率或误码率。完整训练CSV与净荷CSV分开导出，HTML也区分两者。

四点训练确定的是当前通道下相对于发端约定的复映射；发端必须严格发送配置的顺序，并继续使用一致码本。训练匹配不是未知净荷的BER或CRC验证。短训练不能替代正确符号时长、谐波、帧长度和采样时钟；快速帧内信道变化、严重噪声或非线性失真仍可能导致净荷错误。整帧重复时钟模式要求净荷整体重复；随机新净荷须提供真实时钟/ppm并选择手动时钟，不宣称已支持任意载荷盲钟差估计。

启动预置界面而不连接硬件，例如12个净荷symbol：

```sh
/opt/anaconda3/bin/python3 host/rx706_gui.py --four-corner-training --payload-symbols 12
```

窗口启动后手动打开新IQ文件并分析。没有上述参数时保持原启动流程；旧有/无前导及原QAM训练默认保留。

## 64QAM 模式

有/无 PWM 前导、手动/自动补偿和已知训练路径均按所选阶数支持 64QAM。四角预设为 `00 04 24 20`，每符号六位 `IIIQQQ`；实际净荷长度须单独给定，不能由阶数推断。详细覆盖矩阵、码本检查和使用方法见 [QAM64_README.md](QAM64_README.md)。

当前64QAM已确认采用3PWM＋双遍四角＋128个物理净荷（64个重复对）；新入口`rx706_gui.py --paired-64-frame`。默认QAM窗口136；可手动配置额外尾部。CRC调试默认关闭、无算法时只显示未验证；详见 [QAM64_README.md](QAM64_README.md)。
