# 三用户纯占空比CRC12

启动：`/opt/anaconda3/bin/python host/rx706_receiver_gui.py`。
选择三用户验证，载入 `host/pwm_frame_three_users_crc12.json`，打开本次BIN及其匹配采集元数据，运行接收。旧窗口必须重开。

每帧20符号：4身份+8数据+4尾部校准+4 CRC12，U1/U2/U3顺序循环。码字0到7对应25%到60%，步长5%，延迟全部0。默认169.971671 ksymbol/s。CRC参数和发送测试向量见rx706_pwm_crc12.py。该配置不是历史QAM/PWM采样的配置。

主界面显示每用户及总计预期/通过/失败/窗口CRC BLER。失败包含CRC失败、身份失败、擦除和尾部校准失败，取并集。仅统计首次锁定之后的完整预期时隙，首锁前和尾部残帧不进入分母。连续采样中的静默时隙保持位置计为失败；缺失的采集数据或整轮删失无法仅靠重复帧辨识，完整传输BLER始终未知。CRC不是纠错，也不保证无漏检。

每用户独立使用本帧尾部4点拟合，不用未知数据参考修复净荷。旧16符号参考评分在新模式明确禁止。导出pulse_config.air_crc12_report保存全20接收符号和逐帧判定，可复算CRC。尾部校准和CRC不计入8符号净荷导出。
