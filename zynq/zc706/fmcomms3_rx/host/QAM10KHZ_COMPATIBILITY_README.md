## 2026-11-11：10kHz专用动态相位回退

仅在约10kHz自动模式的原相位流程失败、且前导连续时启用。原20kHz配置/回放继续走原策略，不按文件名绑定算法。

- 从连续已知PWM头的相邻相位增量跟踪动态频偏，再确定公共整数周数，不再把穿过±π本身当作失败。
- 保留逐头局部频偏五倍不确定性、滑窗周数排除检查、四角训练覆盖与相对相位验证。无法区分则仍拒绝；缺头不跨越。
- 使用not-a-knot三次相位插值，保持固定载波参考变换不变性，且不强制端点零曲率；未使用未知净荷或最近邻EVM选参。
- 原0.20rad留一P95门限不放宽；新分支进一步要求每个留一误差均≤0.20rad，避免少数相位跳变藏在百分位中。

## 历史诊断：新回退加入前的10kHz采样

`256qam_10pliot_4comp_10khz_1.bin`完整2秒、15.36MS/s。正确10kHz配置能通过原载波/PWM/四角训练初筛：原载波约−203874.68Hz，已知头估计相对时钟+45.68ppm，实际帧间隔27.00123ms。初筛PWM误差14.14%，训练EVM3.64%，不是全净荷EVM。
