# 验收收端内的板卡采集

统一入口：

```sh
cd /Users/carrot29/work/code/ris/rx_code/zynq/zc706/fmcomms3_rx
/opt/anaconda3/bin/python host/rx706_receiver_gui.py
```

可在命令后附加已有 BIN 的路径，或继续使用界面的“打开 bin…”进行离线验收。
启动器不会自动连接板卡、采集或运行接收。

## 连接、采集、验收

1. 在 PWM测速 / 256QAM验证 / 三用户验证中选择所需功能区。
2. 点击顶部“连接板卡 / 采集…”，打开同一应用内的采集子窗口。
3. 检查板卡 IP、控制端口和日志端口，手动点击“连接”。默认保持原值 192.168.1.10 / 5001 / 5000。电脑网络仍需按实验环境正确设置；程序不会修改网络。
4. 选择采集长度和保存路径。默认 1 秒，仍是 15.36 MS/s、双通道 I1 Q1 I2 Q2、小端 int16，按 32 KiB 向上对齐。默认路径保持 host/gui_data/current_pwm/rx_时间戳.bin。
5. 点击“开始采集”。默认完成后下载；已有 DDR 数据可直接下载，也保留断点续传、暂停/终止、状态、日志、业务按键与释放 DDR 等旧功能。
6. 只有下载成功并通过原有 CRC / SHA256 流程，界面才提供“载入最近采集 → 当前功能区”。点击它，或采集子窗口内“载入最近采集 → 验收”。BIN 与同名 .bin.json 元数据均保留在原路径。
7. 本次新采集仅选入当前功能区，不会自动解调，也不猜测前导、时钟或发送参数。原帧配置保留，但需要重新确认与本次发送端一致，再点“运行接收”。绑定旧 BIN 的 QAM 回放仍会拒绝用于不同新 BIN，须加载适用配置。

接收分析运行中或帧配置编辑窗口未关闭时，暂不允许载入新采集。
切换功能区后，“载入最近采集”明确作用于当前功能区，不会覆盖其他功能区保存的文件。
下载结束不会自动替换正在查看的旧 BIN，因此可继续离线对比。

## 窗口与数据安全

- 关闭采集子窗口只隐藏它，连接或正在进行的下载不停止。再次点击顶部入口会复用同一窗口与连接。
- 需要停止或断开时，在采集窗口点对应按钮。
- 关闭整个验收收端会取消主机端传输并断开连接，不主动发 ABORT / RELEASE。板卡上已完成的 DDR 数据保留；中断下载的 .part / .part.json 可在重新连接后通过原路径续传。
- 原 `host/rx706_gui.py` 独立采集入口保持不变；不要同时用两个进程连接板卡的单客户端控制端口。
