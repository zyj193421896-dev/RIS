## 发端约定（须与实际播放器一致）

- 前导是独立的已知PWM波形序列，不是QAM标签，也不映射到QAM码本。
- 当前逻辑协议设定前导与QAM均为20,000周期/秒，每周期50µs；QAM每符号1个PWM周期（K=1），256slice/周期。QAM调制基频为20kHz，接收提取+1阶谐波。
- 依次发送10个前导周期、4个QAM四角训练、256个任意QAM净荷符号，无额外间隔/尾部/CRC/重复编码。总270周期，13.5ms/帧。
- 四角顺序为十六进制`00 08 88 80`，对应(-15,-15)、(-15,+15)、(+15,+15)、(+15,-15)。每帧训练仅校准复增益、零点与镜像，并从净荷输出剔除。
- 原10个(高宽%,延迟%)为：(25,50)、(65,0)、(40,30)、(35,0)、(45,20)、(75,0)、(25,10)、(55,0)、(25,40)、(50,15)。
- 主JSON按精确百分比构造独立前导，其`total_chips=20`只是5%几何单位，不是QAM的slice数。`pulse_chips`每行是[延迟,高宽]，`symbols=0…9`只是顺序位置，不是66符号/256QAM码表编号。
- 主版所需前导(延迟µs,高宽µs)依次为：(25,12.5)、(0,32.5)、(15,20)、(0,17.5)、(10,22.5)、(0,37.5)、(5,12.5)、(0,27.5)、(20,12.5)、(7.5,25)。

**发端未验证条件：** 尚未找到本次整帧播放器/实际时钟设置或10+4+256新采样。主JSON要求前导可以独立实现这些精确时间，不声称已修改硬件。若前导实际上必须共享256个等宽slice，5%无法精确表示，不可直接使用主版。可选文件`rx_256qam_256slice_20khz_10_4_256_uniform256_OPTIONAL.json`把延迟和高宽分别四舍五入到最近整数slice，明确标为未确认备选，不默认使用。

统一256slice备选[延迟slice,高宽slice]：
[128,64], [0,166], [77,102], [0,90], [51,115], [0,192], [26,64], [0,141], [102,64], [38,128]。

20kHz下QAM每slice195.3125ns。若播放器只能300MHz固定整数ticks/slice，则需要58.59375ticks，无法精确实现；59ticks是19.862288kHz，58ticks是20.204741kHz。使用真实发端周期修正接收参数，不能拿20kHz文件名当实测频率。已有`码本/ris_256qam_codebook_0deg.zip`元数据为1MHz、K=3，不能直接宣称该文件就是此次20kHz/K=1发端。

## 接收GUI

1. 关闭旧接收窗口后重开：`/opt/anaconda3/bin/python host/rx706_receiver_gui.py`。
2. 选“256QAM验证”，打开本次BIN及其同名`.bin.json`采集元数据。
3. “载入配置…”选择主JSON。摘要应显示256QAM、20kBaud、QAM256slice、10个PWM前导、4个训练、256个净荷。
4. 核对ADC采样率与RX通道。高级参数中“原载波”必须填原RF载波的基带偏移，不是+20kHz目标谐波频率。载入新协议不会偷改采样率、载频、文件、通道或起点。BIN同名元数据中的Fs优先于界面备用值。
5. 如修改本次采集参数，点“确认当前配置与发送端一致”，再点“运行接收”。完整发送/解调参数来自JSON，基础QAM框不会覆盖它；“查看完整配置”只读，编辑JSON后重新载入。
6. 当前QAM一次最多处理1秒（与旧QAM一致）；每帧应输出256个净荷及独立的4行训练。EVM不是BER，未知净荷没有发端参考，因此实际BER始终未测。

15.36MS/s采集时：50µs=768采样点，QAM每slice=3采样点；精确前导的5%几何单位为38.4采样点，接收模板按采样位置匹配，不要求每个边沿都落在整数采样点。

## 接收实现与验证边界

三处PWM模板共用同一[延迟,高宽]几何：初始搜索、两态/CFO拟合、逐帧校验。旧prefix+symbol模板维持原行为。

新协议用完整已知10前导估计公共CFO；四角不再把短训练量化误差拟合为额外CFO并外推整个256净荷。默认旧协议保持原频偏估计行为。新配置关闭未知数据盲定时、重复帧时钟、CRC和净荷参考；任意各帧变化的净荷可接收。

`tests/test_qam10_frame.py`独立合成二态IQ，使用发端生成器256slice整数脉冲，测试精确/量化前导、镜像、随机排列的每帧256个标签及错误训练拒绝；净荷真值仅在测试断言中使用，从未输入收端。通过这些测试只证明数值链路，不代表真实射频或新采样验收。
