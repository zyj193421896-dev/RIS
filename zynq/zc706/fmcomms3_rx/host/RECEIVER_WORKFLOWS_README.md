# RIS 收端三功能区

直接启动（不连接板卡）：

```sh
/opt/anaconda3/bin/python host/rx706_receiver_gui.py
# 可选：直接带入采样文件，但仍需选择真实发送配置
/opt/anaconda3/bin/python host/rx706_receiver_gui.py /path/to/capture.bin
```

原板卡控制入口 `host/rx706_gui.py` 保留，通过 IQ 分析按钮也可进入新布局。

## 使用

1. 选择 PWM测速、256QAM验证或三用户验证。
2. 打开 bin，载入本次实际发送配置。PWM 单用户可用帧向导；三用户可从模板编辑，再明确确认。模板不自动当作实际发送配置。
3. 点击「运行接收」。结果下方显示码元率/BER/BLER/净荷擦除；无参考时 BER、BLER 显示未测。详细统计和导出保留在统计页及符号表。

PWM 和三用户运行固定前导、码表及用户组合的自动接收流程，然后按固定方案整文件校验。不会从 BIN 猜前导。三用户是一个 RX 内顺序身份块，不是三个射频通道。空码表仅在明确确认脉冲参数后按参数生成。

256QAM支持当前基础TDCM设置（`rx706_tdcm_settings_v1`）及已保存的IQ绑定回放（`iq_bound_tdcm_replay`，256阶）。绑定回放核验文件路径、大小、SHA256、采样率和处理范围，并原样传递全部恢复参数；不降级为基础配置。绑定参数可只读查看和保存。其他阶数、未知字段或不兼容格式拒绝运行。基础参数必须与实际发端一致。

EVM不是BER或锁定证明。当前界面QAM输出保留「BER未测」，不能拿候选星座误差替代真实发送参考校验。PWM BER依赖配置中的实际已知净荷，且不包含擦除；物理擦除另列。

各功能区保留各自文件与参数。运行期间不能切换或重复启动，可停止。更换文件/参数会清除旧图表和导出结果。高级参数中保留既有解调设置；绑定回放时只显示锁定方案，避免基础参数覆盖高级接收功能。

## 有效速率与亮色提示（2026-11-10）

主界面“有效净荷”表示完整净荷中已经判决的符号数 / 实际分析秒数，单位 ksym/s，
不保证所有符号无误码。时长分母为 input_samples / (output_rate_hz * decimation)，
是 first_tuple 起点之后实际读取的采样数，受 EOF 截断。失锁、间隙、未完成尾块的
时间保留在分母中；身份、校准、擦除和未完成块不计入净荷分子。脉冲码表模式明确
关闭旧 auto_search 的自动片段裁剪，因此此分母不是“第一行到最后一行判决”的时间。
无有效采样时长时速率未测；无参考时 BER 未测，但仍显示物理净荷速率。

统计页区分：含前导 Rs、物理码片率 Rs×total_chips、码表容量 Rs×log₂(M)、
净荷容量上限 Rs×log₂(M)×净荷/周期。已判决净荷速率乘 log₂(M) 也只是等效容量上限。
66 个符号的七位输出标签不是七个独立信息比特。没有明确传输映射、CRC/FEC，
实际无误码净比特率未知。参考 BER 不含擦除，擦除数另列。

提示使用原生主题背景，并选用达到至少 4.5:1 对比度的琥珀色，主题变化时重新计算。

## 完整2秒PWM采样

PWM测速和三用户的明确脉宽/时延帧配置支持完整文件最长2秒。自动接收先以30ms初筛、最多前1秒比较候选，再冻结参数分析完整文件。界面和搜索报告分开标明选参区间与最终统计时长；2秒文件的净荷速率分母为2秒，不能把搜索小窗当作整文件。旧PWM、QAM等其他模式的读取上限不变。超过2秒暂时明确拒绝。

BIN必须保留匹配的`.bin.json`采集元数据，并由用户提供与实际发送一致的帧配置；不自动猜前导或参考。固定方案绑定当前BIN的SHA256，不用于别的采集。已运行的旧窗口需要重开以加载新代码。

## 符号表按当前功能区分流

256QAM区的“QAM 符号表 / 比特流…”打开当前结果的“候选符号 / 比特”页，另有独立训练表与完整CSV导出；没有结果时提示先运行接收，不改为PWM，也不修改最简帧或时间片设置。PWM测速和三用户保留原PWM符号表。换文件、改参数或换功能区会关闭旧QAM结果表，避免导出过期结果。

净荷最近邻EVM和已知训练EVM分别显示；四角训练EVM取有效帧的训练拟合误差中位数，不能代表所有净荷。自动时钟模式显示实际固定时钟偏差补偿、逐帧提取和相位设置，不再沿用旧静态流程的限制文案。未知净荷仍显示BER未测。已有窗口须重开加载修复。
