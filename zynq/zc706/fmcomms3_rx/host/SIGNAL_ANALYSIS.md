# 接收信号分析

## 400kHz：查看含错误的候选符号表

打开 `5p802_switch400k_m50dbm_3bit_random.bin`，PWM符号率填400kHz，抽取倍数保持1，编码片8、保护片2。「启用已知发端符号循环」本次不勾选；旧7642校验功能保留。点击「PWM 符号表 / 比特流…」可直接分析并打开表格，即使整体编码未锁定也保留候选输出。

表格新增「候选符号（允许错误）」「候选比特」「候选依据」，无需通过脉宽/保护片检查才显示。候选按实测主脉宽取最近的1～8片、再减1映射到符号0～7；超范围时限幅并明确标记。缺少完整主脉宽时，使用原始多数时间片中1的数量估计，并标记该依据。全0仍按当前协议显示为空闲，没有可用高电平证据时显示?。这些估计可能错误，失败原因、原始时间片、主脉宽和原有有效性标记都保留。

若整体协议未锁定，原有已确认符号/比特列保留无效与???；候选列和候选预览继续显示。勾选「预览候选比特（允许错误，不用于BER）」可切换预览；CSV包含所有候选与检查结果，「导出候选比特流…」可导出全部候选位置。候选永不作为BER输入，也不补全有效比特流或隐藏擦除。

该文件JSON记录Fs=15.36MS/s；400k符号/s、10片/符号意味着每片3.84个IQ点。原来4点的阻断已改为3点的算法下限、4点以上的建议，并对3～4点显示计时余量提示；边沿仍在原始点之间插值。抽取2倍只剩1.92点，会拒绝解调并给出完整采样预算。修改文件Fs标签不能增加实际采样点。已用独立生成的400k/15.36MS/s、八种合法脉宽验证插值判决。

载波初始化首窗不稳定时尝试约1ms处的连续窗口；长窗质心拟合分离不足时，可使用经验证的初始化校准窗拟合，并明确提示局部校准不代表整段质量。原始起始段仍保留，不删除或补齐符号。该文件前200ms的候选时钟约399.982kHz，基带载波约+0.79968MHz；已恢复两簇IQ，但只有约19.9%的活动候选满足当前8+2编码约束，故只提供候选信息，不宣称已可靠解调，也不计算本次BER。

真实Tk复放保留79996个符号位置，其中58171个有数值候选；其余按空闲/未知保留。表格预览前2000行，CSV导出全部79996行。复现脚本 `tests/verify_pwm_400k_gui.py`；报告、CSV、候选比特流与星座预览见 `reports/pwm_400k_20261029`。另验证原100k的7642参考统计保持不变。

## 已知循环 7→6→4→2：区分波形告警与误码

当前变占空比文件 `5p802_switch100k_m50dbm_random.bin` 的发送符号循环为 `7 6 4 2`，对应每符号3bit的 `111 110 100 010`。重启GUI，选择PWM模式，在左侧「已知循环校验 / BER」勾选「启用已知发端符号循环」，保留序列 `7 6 4 2`、同步窗64，点击分析。其他发送内容需修改参考序列或取消勾选。填写的是符号值，不是高电平片数；符号7对应8个高电平片。

仅使用前64个符号位置选择循环相位（允许采集从循环中途开始），其后固定对齐，不因不匹配而重新同步。同步窗要求至少8个且不少于两倍循环长度的可判决符号，最佳匹配率至少75%，与次优循环相位相差至少20个百分点；不满足或片段太短时不报告BER，波形解调结果仍可查看。重复序列如7676自动约为基本周期76。

BER=错比特数/已判决比特数，仅统计同步窗之后的有效判决，按收发符号二进制异或逐位计数。同步窗排除；擦除、空闲位置保留，在该已知持续发送数据的模式下单列为擦除，不进入BER分母，避免失去循环位置。BER=0只表示该片段已判决比特没有发现错误，不表示没有接收失败。金色毛刺告警照常参与参考比对，不自动算错，也不自动确认正确。参考序列不参与接收判决、补全或纠错。

符号表及全量CSV新增参考符号、参考比特、序列校验、错比特数；同步行单独标记且不计入BER。红色为参考不匹配，金色为有毛刺但可判决。分组比特流仍保留接收端原有的?与空闲标记。

实测首200ms、RX1、100kHz、8+2片、默认毛刺容差：共19998行，前64行仅同步；统计19934个符号，其中已判决19760，错符号0，错比特0/59280，擦除174（约0.873%）。全片段130个可判决毛刺告警均匹配7642循环，其中129个在统计窗内。这些结论只对应此文件和片段，不外推到其他数据或整份采集。

复现：`tests/test_pwm_reference.py` 验证已知错误逐位计数、擦除保位、同步窗隔离、错序列拒绝和不随滑移重新对齐；`tests/verify_pwm_reference_gui.py` 通过真实Tk控件及当前采集验证参考参数、符号表、CSV和分组比特流导出。

## PWM 脉宽解调：8 个编码片 + 2 个低电平保护片

「单次毛刺上限」默认0.15个时间片，设0可恢复严格判决。只在符号内部忽略两侧状态相同、两侧持续时间均不小于该上限的闭合短回跳，每符号累计忽略量不得超过0.30片。符号边界的开口跳变、整片有效脉冲和超过限值的跳变不会被该规则删除。沿用既有边界计时容差，原始IQ、原始判决电平和每片多数状态均保留。

忽略短回跳后，主脉宽仍须接近1～8的整数片，原始每片多数状态须与该连续1后接0的编码一致，末尾低电平保护仍须满足要求。满足时输出符号/比特，并以金色标记「有效（短毛刺告警）」。符号表和CSV增加忽略毛刺数、累计/最大插值宽度(ns)及独立波形告警。T1/T0对应忽略短回跳后的主脉冲边沿；波形视图保留原始跳变。有更长额外跳变、累计超限、脉宽超差或保护不足的符号仍保留擦除标记，不把所有异常强行解码。

毛刺告警、擦除计数均不等于误码；有效表示满足接收判据，不表示已与发端数据比对。实测BER仍需已知发送比特。随机文件第52行已验证：约47.77ns插值短回跳改为告警，保留 `1111111100 → 符号7 → 111`。复现脚本为 `tests/verify_pwm_glitches_gui.py`，报告和CSV见 `reports/pwm_glitch_20261029`。

当前 `5p802_switch100k_m50dbm.bin` 是约 100 kHz、50% 占空比的固定方波测试。PWM 符号率默认已设为 `100` kHz，恢复时长为 200 ms。1 Mbps 方案对应的 `333.333333` kHz 是另一种发端设置，不能直接套用此文件。该测试按10片协议对应固定 `1111100000`（符号4、信息位100），不能用来验证八种随机符号的 BER。

时钟恢复按整段上升沿的周期一致性拟合；短毛刺不再累计成新符号。无法按上述短毛刺规则处理的额外跳变或保护片不足仍保留为无效项。50%测试中两种 A/B 映射会得到相同的固定符号，可以显示时长和符号表，但界面明确标记“真实控制0/1未标定”；非等价映射仍需选择 A=1/B=1 或通过训练序列确认。错误弹窗只显示解调原因及本次参数；符号率不符时会提供测得的稳定同向边沿重复率作为核对参考。

选择「星座处理 → PWM 脉宽解调」，设置左侧 PWM 参数后点击「分析信号」。该模式独立于固定 50% 占空比的周期方波恢复，允许数据符号的脉宽逐符号变化。

最新默认协议为每符号 10 片：高电平 1～8 片分别对应符号值 0～7，即 10%、20%……80% 占空比，每符号携带 3 bit；末尾至少 2 片为低电平。`1111111100` 共 10 片。全 0 作为空闲，不产生数据比特，不能同时把 0%～80% 的九种状态全部映射为八个 3-bit 数据符号。

1 Mbps 编码速率对应符号率 333.333333 kHz、时间片速率约 3.333333 MHz。界面「符号率 / PWM频率」填写符号重复频率，不填写时间片速率。采样率由文件 JSON 优先提供；15.36 MS/s 时每片约 4.608 个点，30 MS/s 时每片 9 个点，不要求该比值是整数。

恢复使用复数 IQ 两态的距离和滞回，而非要求状态 1 的功率高于状态 0。先估计公共载波频率，再用多符号窗的判决辅助公共相位跟踪保留两态相位差。两态不分离、输入削顶、载波相干性不足或时序不符时不强制输出信息。本模式针对稳定窄带照射的两态 PWM，不是任意调制或快速变化信道的通用同步器。

「处理抽取倍数」默认 1：保留过采样 IQ 进行电平判决和边沿计时，无需先降到每片一个点。可选 2、4、8、16 倍抽取先逐级作抗混叠低通；抽取后每片至少需要3点，建议4点以上。3～4点提示余量较小，低于3点拒绝处理。图形抽样不参与计时。主界面「PWM 包络」显示 IQ 投影软判决、恢复的 0/1 和符号边界；「PWM 脉宽」显示测得的高电平片数及有效/无效符号。

两簇 A/B 不具有跨文件通用的绝对控制标签。默认按 PWM 时序约束推断哪一簇为 1，但必须用已知训练序列核对。若两种方向均符合协议且会输出不同符号，仍拒绝自动映射；改选「A=1」或「B=1」，重新分析。若两种方向均输出同一个固定符号（例如当前50%测试），允许显示相对 A/B 时长与等价符号，并标记真实控制0/1未标定。更换文件后应重新确认对应关系。

点击顶部「PWM 符号表 / 比特流…」查看各符号的采集起始时间、状态 1 和状态 0 的主脉冲持续时间、占空比、高片数、原始多数时间片、符号值、信息比特和独立毛刺告警。表格预览最多 2000 行，CSV 和分组比特流导出全部结果。首尾不完整符号不解码，内部脉宽超差、保护片不足和无法忽略的额外跳变保留为 `???`，全 0 空闲保留为 `-`，不静默删除异常位置。理论编码速率不包含帧头/校验；有效判决比特率不是实测净荷吞吐率，也不是 BER。

验证脚本：`tests/test_rx706_pwm.py`、`tests/test_pwm_gui.py`、`tests/verify_pwm_gui.py`；后者运行隐藏的真实 Tk 窗口并生成预览，不连接板卡。`tests/verify_pwm_capture_gui.py` 使用当前100kHz真实文件，以GUI默认200ms参数点击实际按钮，验证符号表和CSV导出；结果见 `reports/pwm_capture_fix_20261029`。

沿用原有前端启动方式，点击「IQ 信号分析…」，打开本地下载完成的 .bin，选择 RX1 / RX2，点击「分析信号」。分析窗口打开时，后续下载默认自动分析；可取消「新下载完成后自动分析」。窗口关闭时不会自动启动分析。无需连接板卡即可检查已有文件。

## 大图查看与鼠标操作

分析窗口默认最大化，图表占据右侧主要区域。所有分析参数移至左侧可滚动面板，完整统计放在「统计 / 状态」页。拖动侧栏与图表之间的分隔条可调整宽度，「隐藏侧栏」可进一步扩大图表。

顶部「图表视图」可切换总览、频谱、星座、功率、IQ 波形、相位。双击任意子图可放大为单图，再双击返回总览。单图与总览切换不会重算 IQ 或访问板卡。星座保持 I/Q 等比例，单图模式通过扩大坐标范围填满面板。

底部 Matplotlib 工具栏仍支持历史后退/前进、平移、框选缩放和保存图像；启用工具栏平移或框选时，标准工具栏操作优先于自定义拖动/滚轮。左侧参数区的滚轮只滚动参数，不会意外改变下拉框参数。单图模式保存图像时导出当前可见大图。

已通过四项实际 Matplotlib 鼠标事件测试和真实 Tk 交互检查。当前数据的单图星座有效绘图面积在测试中约为其总览占位的 15 倍；见 reports/gui_navigation_20261028 的预览及 verification.json。

界面包含平均频谱、IQ 星座散点、分段平均功率，以及总功率、分段去直流功率、RMS、PAPR、削顶比例、最多五个局部频谱峰和 99% 累积谱功率频带。存在有效同名 JSON 时，读取采样率和 LO，并显示配置 LO 加基带主峰得到的近似 RF 频率；无 LO 时不推测绝对 RF 频率。

默认 FFT=65536、平均段数=16，在 15.36 MS/s 下分析起始位置之后约 68.3 ms。修改「起始点」可查看其他片段；短文件自动缩短分析范围。界面显示实际起止点和时长。本功能分析所选连续片段，并非整个 5 秒文件的统计。

星座有「原始 IQ」、「主峰移频 + 去直流」、「单音载波恢复」、「周期方波载波恢复」四种视图。前两种显示最多 8192 点，取自各 FFT 块的短连续采样。「主峰移频」仅使用 FFT 最大谱峰，不能替代载波恢复；在抑制载波的相位切换中，最大峰可能是边带。ADC counts 保留幅度尺度。

## 固定全 0 / 全 1 的单音星座

固定状态没有方波切换边带，「周期方波载波恢复」拒绝锁定是正常行为。不要降低边带门限来强行锁定固定单音。

重启 GUI 后，固定全 0 / 全 1 文件选择「单音载波恢复」；恢复时长默认 200 ms，基带载波自动，单音低通截止默认 10 kHz。单音模式不使用「完整周期频率」参数。

「单音相位补偿」有两种选择：

- 「仅固定频偏」：用前半段 1 ms 复幅度窗拟合一个频偏和初相，保留后半段的残余频差及慢相位变化。频率随时间漂移时，星座仍可能呈圆弧或圆环，这能反映单一频偏补偿的局限。
- 「频偏 + 慢相位跟踪」：默认。在固定状态假设下，进一步以约 11 ms 对称窗平滑块相位残差并补偿慢漂移。不是把每个采样的角度归零，剩余幅度波动及快相位扰动仍保留；被跟踪掉的慢变化不能再用于测量器件的慢相位响应。

补偿后经多级抗混叠低通、抽取，再作 10 kHz 显示低通；当前 15.36 MS/s 输入默认输出约 120 kS/s。单音波形及相位显示前约 10 ms；质心幅度和残余相位 RMS 可在统计页查看。RMS 对应所选处理带宽及跟踪模式，不是校准的射频相噪指标。

存在相近强度的多条谱线、噪声或严重削顶时会拒绝单音模式。周期切换数据应使用周期模式，避免将边带当成单音。不同文件均单独估计初相，故单音全 0、全 1 的星座方向不能直接用来映射切换图中的绝对 0/1；该比较需要共同相位参考或带控制标签的连续记录。

已使用真实全 1 文件验证：当前 200 ms 片段仅线性频偏补偿仍有约 60° 圆周相位 RMS；开启慢跟踪后质心幅度约 99.46 counts、残余相位 RMS 约 0.76°，得到单簇。预览及数值见 reports/gui_tone_20261028。

## 周期方波载波恢复：当前 100 kHz 数据

1. 重启整个前端以加载新代码，打开 `5p802_switch100k_m50dbm.bin`。
2. 「星座显示」选择「周期方波载波恢复」。选择该模式会启动后台分析。
3. 「完整方波周期频率(kHz)」填 `100`，不是每秒翻转次数；「恢复时长(ms)」默认 `200`；「基带载波中心」保持「自动」。修改参数后点「分析信号」。
4. 查看蓝/橙两簇、恢复后的 I/Q 波形和相对 A 状态的相位。灰点为切换过渡区。相位曲线选「包裹相位 ±180°」或「展开相位」。原始双通道相对相位需切回原始 IQ 模式查看。

程序按已知周期搜索间隔约 2 倍周期频率的第一边带对，用中点估计载波，而非使用最大谱峰。1 ms 或更长同步窗中的边带相位用于公共载波相位与周期时钟估计；仅做公共相位移除及整体坐标旋转，保留状态间相位阶跃。之后进行对称 FIR 低通与抽取，避免在未滤波时直接降采样。当前文件通常得到载波约 1.8019 MHz、周期约 99.996 kHz、相位差约 176.6°、幅度差约 0.7 dB，输出约 3.84 MS/s。

恢复范围独立于原始 FFT 平均段数，默认从同一「起始点」读取 200 ms，最长 1000 ms 且最多 2^22 个双通道元组；实际范围显示在摘要。波形显示恢复片段的约 10 个周期，最多 4096 点；恢复星座最多随机选取 8192 点，默认聚焦主体分布，标注落在视窗之外的点数，完整选点仍保留在图对象中。原始 IQ 视图仍显示完整幅度范围。

噪声、单音、严重削顶、周期不匹配或两态不稳定时，会提示「周期恢复未锁定」并显示原始 IQ，不强制生成两簇。必要时可填写基带载波中心提示，例如 `1.802`；该值不是射频载频 5802 MHz。参数错误也会在状态区显示。

该算法专用于已知周期方波，不能当作任意随机比特载波同步器。同步使用所选片段的边带轨迹，首半段选择时序与质心，后半段验证周期符合度。A/B 尚未映射到外部真实 0/1；周期符合度不是 BER。它也没有验证 3 MHz 切换，采样率不支持时会拒绝恢复。后续下载自动分析会沿用当前显示模式及参数。本功能不写原始文件、不连接或修改板卡。

IQ 波形和相位曲线显示所选片段开头最多 4096 个连续点（15.36 MS/s 时约 266.7 us），不对不连续的星座采样点进行相位展开。I、Q、幅度曲线随「原始 IQ / 主峰移频 + 去直流」选项切换。「相位曲线」可选包裹相位 ±180°、展开相位、双通道相对相位；展开在低幅度缺口后重新开始，包裹曲线不会跨 ±180° 边界连成假跳变。默认幅度门限 -45 dBFS，可调整；该门限只是显示筛选，不是自动噪声或 SNR 估计。

双通道相对相位计算同时刻的 arg(x_selected * conj(x_other))，始终使用原始两通道，RX1 时为 RX1-RX2，RX2 时符号相反。任一通道低于显示门限、为零，或参考通道样本不合法时隐藏该点。这个角度只有在接收通道关系合适、信号相干时才能解释成链路相位差。不同采集文件的原始初相不能直接相减作为超表面反射相位变化。自动主峰移频也不能替代载波恢复，主峰属于干扰时无法得到目标信号相位。

总功率定义为 10 log10(mean(|I+jQ|²)/2048²)，去直流功率对每个 FFT 块分别去除均值；功率曲线使用原始块功率。PAPR 使用原始采样峰值功率与平均功率之比。频谱沿用 Hann 相干增益校正的 dBFS/FFT bin。99% 频带基于当前去直流设置下的平均窗谱，包含噪声和干扰，不能直接视为目标信号带宽。局部峰没有身份识别或信噪比门限，不表示独立发射源。所有功率均未经射频链路校准，不是 dBm。

依赖沿用 requirements-fft.txt（NumPy、Matplotlib）和可用的 Tk。分析在后台线程运行，支持停止。分析期间新下载文件完成时，保留最新一份等待分析。
