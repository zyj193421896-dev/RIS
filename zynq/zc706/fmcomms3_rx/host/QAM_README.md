# QAM 离线解调

本页的常规QAM路径面向直接I/Q成形QAM。若发端用方波占空比、时移在谐波上生成QAM，请选择“TDCM 谐波QAM”，见 [TDCM_README.md](TDCM_README.md)。

在接收信号分析窗口的“星座处理”选择“QAM 解调”。默认256QAM，可选16/64QAM；PWM模块及其参数保持原样。

在“QAM 解调设置”填写发端符号率、基带载波频偏（已居中填0）、发端脉冲形状和RRC滚降系数。恢复片段长度沿用“恢复时长”。参数修改后点击“分析信号”。载波频偏是相对接收LO的有符号基带频率，不是射频载波频率，也不一定是频谱主峰。

处理流程：已知频偏移除、匹配滤波、32个定时相位和静态载波相位联合搜索、平均功率归一化、方形QAM最近邻判决。RRC模式使用16符号跨度滤波器；Rectangular模式使用一符号滑动平均。原始IQ文件不修改。

分析页显示频谱、星座和IQ波形；统计页显示前24个候选符号的比特。Gray标签分别沿I/Q轴从负到正递增，每符号先I后Q、各轴MSB优先。必须核对发端约定。

不启用前导时仍使用上述盲估计流程，没有帧同步，存在90°旋转歧义。

## 可配置前导 / 导频

在“QAM：可配置前导 / 导频”勾选“启用已知前导同步与频偏校正”。默认关闭，避免未匹配的发端序列被误当作导频。该功能与PWM的20%三连脉宽补偿独立。

- 前导长度3～256符号。`0 0 0`只是示例，必须按发端实际序列填写；也支持三个不同符号或更长序列。
- “符号值（Gray）”：十进制用空格分隔；二进制加`0b`，十六进制加`0x`。使用本机I后Q、每轴Gray映射。例如256QAM的`0 0 0`对应三个`(-15,-15)`星座点。若发端映射不同，请使用直接I/Q方式。
- “I/Q电平”：填写未归一化的奇数星座电平对，空格分隔。例如`-15,-15 -15,-15 -15,-15`。256QAM每轴允许−15、−13…15；64QAM为−7…7；16QAM为−3…3。不能直接填写PWM占空比或接收ADC值。
- “残余频偏范围”：相对上方已填写的基带频偏，默认±1 kHz，须小于符号率的一半。总校正频偏=填写的基带频偏+估计残余频偏。
- “前导匹配EVM上限”：默认10%，用于拒绝与已知前导不符的候选。降低容差可减少部分误匹配，但不能保证三符号前导唯一。
- “前导搜索时长”：默认1000 ms，从“起始采样点”开始，受实际文件长度和恢复时长限制。它限制前导首符号采样中心的位置；序列尾部及后续数据也必须在恢复片段内。允许前段空白；没有匹配前导时明确报错，不回退到盲解调。

流程为：移除填写的频偏、匹配滤波、32相位定时与前导位置搜索、由去除已知符号后的相位斜率估计固定残余频偏、用后续最多128个数据符号的星座误差排序候选；再在匹配滤波前移除该频偏，以前导估计复增益并校正后续数据的幅度和相位。已知前导用于消除90°相位歧义。

统计页显示前导和净荷首符号的**采样中心时间**（相对原始文件）、前导匹配EVM、残余及总频偏、初始相位。它们不是高电平边沿时间。输出星座、比特及符号数排除匹配到的这一段前导和之前的样本；之后重复的前导及帧尾空白不会自动删除。当前没有配置组长/净荷长度，只选择一个最佳前导候选，不自动分割多帧。

三符号可用于初步实验，但在长随机数据中可能误匹配，噪声也会使三符号频偏估计不稳定。界面明确标为“前导候选”，匹配EVM和判决EVM均不能证明帧同步正确。遇到误匹配可缩小搜索范围，或改用更长、不同符号组成的已知前导。估计仍是固定频偏/相位，没有持续载波或时钟漂移跟踪、信道均衡；长片段可能再次旋转。没有净荷参考，不报告BER。

## PWM前导 + QAM 混合帧

在“星座处理”选择 **PWM前导 + QAM**。支持下列帧结构：

`已知PWM version2前导 → 配置的切换间隔 → [可选的已知QAM训练序列] → QAM数据`

“混合模式：PWM前导 + QAM”设置：

- PWM前导符号值：默认`0 0 0`，按version2的k值填写。沿用下方PWM频率和version2总片/前高/后低（当前默认25/5/8），因此默认是三个20%占空比PWM符号；可配置3～256个合法符号。两态IQ直接拟合，兼容等幅反相，不能只按能量阈值判断。
- PWM→QAM间隔：默认0 µs，从**最后一个PWM完整符号周期结束**算起，到QAM波形的起始边界。不能从最后一个下降沿算起。按真实发端切换关系填写，包含约定的保护间隔/硬件延迟。
- PWM搜索时长：默认1000 ms，从分析起始采样点搜索，受恢复时长/文件长度限制。找到PWM之前的空白不输出为QAM数据。
- PWM拟合误差上限：默认25%。定义是两态模型的残差RMS除以两态IQ距离，与QAM前导EVM不同，也不是BER。
- 高电平脉宽偏移：默认0片。按`实测高片数−标称高片数`填写；例如标称5片、实测4片，填−1。只改变PWM检测模板，不改动QAM幅度和原始文件，不自动猜测物理衰减量。
- PWM残余频偏范围：默认±1 kHz，相对上方QAM基带载波频偏。PWM候选通过后，用其稳定高/低片段的相邻IQ相位估计固定粗频偏，并移除该偏移；超出范围拒绝。短前导和噪声会影响估计，不是持续频偏跟踪。
- QAM起始搜索窗：默认8个**QAM符号周期**。启用上方QAM训练前导时，只在PWM推算的QAM边界之后该窗口内搜索前导起点，防止跳到远处的数据误匹配。若发端成形有确定的启动延迟，请配置切换间隔或适当增加该窗口。没有QAM训练时，该窗口不参与处理，直接在边界后的第一个QAM周期内搜索采样相位。

启用“已知前导同步与频偏校正”时，填入的是**PWM之后实际发送的QAM训练序列**。两者可以同时存在；QAM序列负责进一步校正残余频偏、复增益和绝对相位。总频偏=填写的基带频偏+PWM粗频偏+QAM训练估计的剩余频偏。

不启用QAM训练时，PWM之后直接当作QAM数据进行盲静态定时/相位估计，仍有90°相位歧义；PWM两态本身不作为QAM绝对相位参考。频偏估计有误时，后续QAM也可能转动。匹配滤波前屏蔽PWM和切换段，避免PWM电平进入QAM匹配滤波器；不会像旧盲路径那样默认跳过开头若干QAM符号。

统计页显示PWM候选起点、完整前导结束、推算的QAM边界、拟合误差及粗频偏。PWM结构按配置符号率拟合，不依赖原PWM解调的8符号时钟锁定要求；原PWM解调流程不变。已知PWM前导每片至少2个原始采样点，高/低平台各至少3点，仍须通过两态拟合和频偏检查；独立PWM解调的采样要求不变。该模式只选择一个PWM候选并处理之后的数据，重复帧不会自动拆分；发端应恰好发送配置的前导符号数，长串同宽PWM内可能出现多个等价起点。没有匹配前导时报错，不回退到全文件QAM解调。信号未做均衡，真实空口仍需实验核对。

验证：在tests目录运行 `python -m unittest test_qam_pwm test_qam_preamble test_rx706_qam test_gui_layout test_pwm_gui test_signal_analysis_view`。包含矩形/RRC合成256QAM、PWM混合帧、三相同符号和不同符号前导、空白起始、正负频偏、相位象限校正、I/Q配置、原文件时间偏移、搜索失败，以及GUI参数和结果交付。

64QAM 的全部接收模式、`IIIQQQ` 映射、`00 04 24 20` 四角训练、六位/HEX 存储约定、实际码本证据和使用方式，见 [QAM64_README.md](QAM64_README.md)。
