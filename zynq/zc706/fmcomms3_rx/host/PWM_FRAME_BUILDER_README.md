# PWM 发端帧 JSON 向导

## 操作

1. 打开 IQ 分析窗口，点击顶部 **帧配置向导…**，不用展开长侧栏。现有脉冲模式配置会复制为草稿；关闭不会修改它。多用户配置明确拒绝使用快速向导，原多用户编辑器仍可用。
2. **前导与时序**：填入你指定的前导符号编号，例如 `0 0 0 0`。这只是输入格式示例，不保证适合任何发端。填写净荷区总长度、设定码元率、片宽和预留低电平；前导容错数会显示当前值，可自行调整。前导至少4个符号，编号从0开始。
3. **实际码表**：每行填写 `延迟片数 高电平片数`，第一行对应符号0。没有自动猜测前导或参考，也不会自动补码表。已有隐式码表会展开成明确行，便于检查。
4. **参考与校准（可选）**：旧内容可供核对，但两项默认关闭。只有确实知道发端数据时才勾选参考；没有参考显示“BER未测”，不是0。参考格式 symbols 为符号编号，bits 为标签比特。填写整个净荷区参考（包含校准位置）；校准位置被排除出数据评分。循环重复/每块重置规则须与发端匹配，不是自动补齐数据。
5. 只有发端确实固定发送四个已知校准符号时才启用校准。填写净荷区中从 **1开始** 的四个互异位置及对应符号编号，至少覆盖两种实际脉宽。JSON自动换算成从0开始的 payload_indices。修改前导、码表、净荷长度或时序会再次关闭参考/校准，须重新确认。
6. **验证 / 刷新预览**显示前导、校准与数据评分区、完整码表，以及每片、延迟和高电平的实际时间。点击 **另存新JSON…**，必须选择不存在的文件名；即使文件对话框同意覆盖，程序仍拒绝覆盖。保存不应用。
7. 点击 **明确应用到当前分析** 才会载入主窗口并清除旧分析。也可以关闭向导，以后用“载入帧配置…”打开已保存的JSON。选择对应bin，再使用“自动接收调试 → 全文件码率 / BER”。

## 边界

- 本向导只配置发端格式，不认证真实信号。任何前导都可能出现在任意净荷中，无法保证绝不误锁。
- 不自动生成参考、不把校准当作普通数据、不承诺无误码。参考必须由用户核对实际发端，短参考若开启循环就按该规则重复。
- 全新草稿前导、码表、净荷长度留空，必须明确填写；已有草稿可“恢复打开时的草稿”。
- JSON不携带文件哈希、A/B极性、冻结接收状态、旧容差或旧量化策略。应用时回到自动极性和默认0.4片容差，初始身份搜索范围4096周期；可再自动调接收参数。完整固定接收方案仍使用原来的“保存本文件固定接收方案…”。
- 帧预览的kBaud是设定值，实际文件码元率与BER仅在分析后获得。比特标签宽度不等于独立信息容量。
- 快速向导不编辑多用户帧。原专家编辑器/JSON载入仍保留，没有丢弃或改写多用户数据。
- 已知参考以内容内嵌，启用时不允许 `@文件路径`，避免搬移后失效。关闭的旧参考不会写入新JSON。
